# Sky AI Bets — открытый архив

**Страница архива:** https://skyaibets.github.io/archive/

Здесь записано **каждое решение** бота по каждой карте, объявленной в канале: и ставки, и пропуски. Запись делается в момент решения — до конца карты.

## Почему этому архиву можно верить

| Что | Как обеспечено |
|---|---|
| Записано до исхода | Каждая запись в момент решения получает отметку времени в блокчейне Bitcoin (OpenTimestamps, папка `stamps/`) |
| Прошлое не переписано | Каждая запись содержит отпечаток предыдущей (`prev_hash`): правка любой старой строки ломает все отпечатки после неё |
| Неудачи не спрятаны | По каждой карте из поста «Идёт драфт» есть решение на каждом моменте (после драфта, 10-я, 15-я минута) — ставка или пропуск |
| Коэффициент был реальным | К ставке приложен скриншот BetBoom (`screens/`), его SHA-256 записан в ставке; через 30–40 с — повторная проверка линии |
| Результат честный | У карты ссылка на матч в OpenDota с реальным числом убийств |
| Пишем именно мы | Каждая запись подписана ключом бота (Ed25519), открытый ключ — `pubkey.txt` и закреп в канале |

Номер ставки в архиве совпадает с номером в посте канала, а в посте указан код записи (`🔐`).

## Проверить самому

- На странице архива — кнопка «Проверить архив»: браузер пересчитает все отпечатки и подписи.
- Без браузера: `python3 verify.py` (подписи — после `pip install pynacl`).
- Отметку в Bitcoin: перетащите `stamps/NNNNNN.txt` и `stamps/NNNNNN.txt.ots` на https://opentimestamps.org или выполните `ots verify stamps/NNNNNN.txt.ots`.

## Файлы

- `ledger.jsonl` — сам архив, одна запись на строку (`MAP`, `DECISION`, `POST`, `RECHECK`, `SETTLE`)
- `bets.csv` — только ставки, таблицей
- `stamps/` — отметки времени Bitcoin и `status.json` (в каком блоке подтверждена каждая запись)
- `screens/` — скриншоты BetBoom к ставкам

## Чего архив не доказывает

Банк виртуальный: архив доказывает, что ставка была объявлена до исхода по реальной линии BetBoom, но не то, что на неё поставили деньги. Ставки, сделанные до запуска архива (17.11.2026, №1–2), внесены задним числом и помечены.
