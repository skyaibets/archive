# Sky AI Bets — открытый архив

**Страница архива:** https://skyaibets.github.io/archive/

Здесь записаны все решения бота по каждой карте из канала: и ставки, и пропуски. Каждое решение записывается в момент, когда оно принято, — до конца матча. После этого запись уже нельзя незаметно изменить или удалить.

Архив ведётся с 17.11.2026, 21:00 МСК. Ставки №1 и №2 были сделаны раньше и добавлены вручную — они помечены. Все последующие записи добавляются автоматически.

## Как проверить самому

| Что проверяем | Где |
|---|---|
| Время ставки | «Пост со ставкой» в канале: время публикации ставит Telegram, правки помечаются «изменено». Наши посты о ставках не меняются. |
| Запись существовала до конца матча | «Снимок в Интернет-архиве» (archive.org) у каждого решения: дату и время снимка ставит сам Интернет-архив. |
| Результат | «Проверить в OpenDota» у каждой карты: реальное число убийств. |
| Всё сразу | Кнопка «Проверить ставку» / «Проверить пропуск» на странице: браузер сам спрашивает Интернет-архив и OpenDota и сравнивает. |

По каждой карте из канала записаны все три момента — после драфта, 10-я и 15-я минута: либо ставка, либо пропуск с причиной. Поэтому проигрыш нельзя тихо убрать.

## Для специалистов

- **Цепочка записей.** `python3 verify.py` пересчитывает отпечаток (SHA-256) каждой записи и проверяет ссылку на предыдущую. `python3 verify.py --demo` показывает, как ловится подделка. Подписи бота проверяются после `pip install pynacl`.
- **Отметки в Bitcoin.** У каждой записи есть файлы `stamps/NNNNNN.txt` и `stamps/NNNNNN.txt.ots`, где `NNNNNN` — номер записи («Запись №22» на странице → `000022`). Перетащите оба на https://opentimestamps.org или выполните `ots verify stamps/000022.txt.ots`. В `stamps/status.json` — в каком блоке подтверждена каждая запись.
- **Подпись.** Открытый ключ бота (Ed25519) — `pubkey.txt`.

## Файлы

- `ledger.jsonl` — сам архив, одна запись на строку: `MAP` (карта), `DECISION` (ставка или пропуск), `POST` (пост в канале), `RECHECK` (линия через 30–40 с после ставки), `SETTLE` (итог карты)
- `bets.csv` — только ставки, таблицей
- `d/` — страница каждого решения, именно её сохраняет Интернет-архив; `snapshots.json` — ссылки на снимки
- `stamps/` — отметки времени в Bitcoin
- `screens/` — скриншоты линии к ставкам
- `verify.py`, `pubkey.txt` — проверка без браузера
